# Code of Conduct

We want this project to be a harassment-free, welcoming place for everyone. This code of conduct is
a short form of the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
which applies in full.

- Be respectful and constructive; assume good intent.
- No harassment, discrimination, personal attacks, or publishing others' private information.
- Maintainers may remove comments, commits and contributions that do not follow this code, and
  may ban contributors who repeatedly break it.

Report problems privately to the maintainers at security@mvdw-software.com. Reports are handled
confidentially.
